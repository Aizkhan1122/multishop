# Multishop E-commerce Platform

A full-stack multishop e-commerce application built with HTML, CSS, JavaScript, Laravel, and MySQL.  
Includes an admin dashboard for managing products, orders, users, categories, and site settings.

## Features
- Multi-shop product management
- Admin authentication & dashboard
- Order & invoice management
- User management
- Cart & wishlist
- Secure Laravel backend

## Tech Stack
- HTML, CSS, JavaScript
- Laravel (PHP)
- MySQL

## Installation
1. Clone the repository
2. Run `composer install`
3. Copy `.env.example` to `.env`
4. Configure database
5. Run `php artisan migrate`
6. Run `php artisan serve`
